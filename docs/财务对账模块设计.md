# 财务对账模块设计文档

## 1. 模块概述

### 1.1 模块名称
财务对账（Financial Reconciliation）

### 1.2 模块目标
基于发货通知单数据，提取金额、物料数量等关键信息，通过可视化图表展示，帮助采购和供应商进行财务对账。

### 1.3 用户角色
- 采购方（内部用户）
- 供应商（外部用户）

---

## 2. 数据源分析

### 2.1 核心数据表
- `delivery_notice`（发货通知单）- 已有
  - 发货通知单号、供应商信息、日期等

### 2.2 需要扩展的数据字段
根据现有 `DeliveryNotice` 实体，需要补充以下财务相关字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `totalAmount` | BigDecimal | 发货总金额 |
| `currency` | String | 币种（CNY/USD等） |
| `taxAmount` | BigDecimal | 税额 |
| `netAmount` | BigDecimal | 净额 |
| `paymentStatus` | Integer | 付款状态 |
| `reconciliationStatus` | Integer | 对账状态 |

### 2.3 关联数据
- `delivery_notice_item`（发货通知单明细）- 需确认是否存在
  - 物料编码、物料名称、数量、单价、金额
- `purchase_order`（采购订单）- 已有
  - 关联订单信息
- `supplier`（供应商）- 已有
  - 供应商基础信息

---

## 3. 前端设计

### 3.1 路由配置
```
/purchasing/financial-reconciliation  → 财务对账列表页（采购方）
/supplier/financial-reconciliation    → 财务对账列表页（供应商）
```

### 3.2 页面结构

#### 3.2.1 财务对账主页 (`FinancialReconciliationView.vue`)
- 筛选条件区
  - 日期范围
  - 供应商筛选
  - 对账状态
  - 付款状态
- 数据概览卡片
  - 对账总金额
  - 已对账金额
  - 待对账金额
  - 差异金额
- 图表展示区
  - 对账趋势图（按月/周）
  - 供应商对账分布图
  - 物料类别占比图
  - 付款状态分布图
- 明细表格
  - 发货通知单列表
  - 支持排序、筛选、导出

#### 3.2.2 对账详情弹窗/页面
- 单个发货通知单的详细对账信息
- 明细物料列表
- 差异说明

### 3.3 图表类型

| 图表 | 用途 | 推荐组件 |
|------|------|----------|
| 柱状图 | 月度对账金额趋势 | ECharts |
| 折线图 | 对账进度趋势 | ECharts |
| 饼图 | 供应商占比/物料占比 | ECharts |
| 环形图 | 付款状态分布 | ECharts |
| 数据卡片 | 关键指标展示 | 自定义组件 |

## 4. 后端设计

### 4.1 实体扩展
- 扩展 `DeliveryNotice` 实体，添加财务字段
- 或新建 `DeliveryNoticeFinancial` 关联表

### 4.2 API 接口

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 获取对账概览 | GET | `/api/financial-reconciliation/overview` | 返回汇总统计数据 |
| 获取对账列表 | GET | `/api/financial-reconciliation/list` | 分页查询对账数据 |
| 获取对账详情 | GET | `/api/financial-reconciliation/{id}` | 单条对账详情 |
| 获取图表数据 | GET | `/api/financial-reconciliation/chart-data` | 图表所需聚合数据 |
| 更新对账状态 | PUT | `/api/financial-reconciliation/{id}/status` | 更新对账状态 |
| 导出对账数据 | GET | `/api/financial-reconciliation/export` | 导出Excel |

### 4.3 Service 层
- `FinancialReconciliationService`
  - `getOverview()`: 获取对账概览
  - `getChartData()`: 获取图表数据
  - `getList()`: 获取对账列表
  - `exportData()`: 导出数据

## 6. 数据库变更

### 6.1 需要新增的字段（delivery_notice 表）
```sql
ALTER TABLE delivery_notice 
ADD COLUMN total_amount DECIMAL(18,2) COMMENT '发货总金额',
ADD COLUMN currency VARCHAR(10) DEFAULT 'CNY' COMMENT '币种',
ADD COLUMN tax_amount DECIMAL(18,2) COMMENT '税额',
ADD COLUMN net_amount DECIMAL(18,2) COMMENT '净额',
ADD COLUMN payment_status INT COMMENT '付款状态: 0-未付款 1-部分付款 2-已付款',
ADD COLUMN reconciliation_status INT DEFAULT 0 COMMENT '对账状态: 0-待对账 1-对账中 2-已对账 3-有差异';
```

## 9. 注意事项

- 金额计算需考虑币种和汇率
- 对账数据需要与发货通知单保持同步
- 图表数据需要考虑性能，建议后端聚合
- 需要处理发货通知单无金额数据的情况
- 差异金额的计算逻辑需明确
