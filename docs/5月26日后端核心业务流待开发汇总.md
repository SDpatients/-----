## 二、7.1 供应商准入流程 — 待开发项

### 2.1 供应商自助注册

- [ ] **供应商注册接口**：当前只有 `SupplierController.create()` 由管理员操作，缺少供应商自助注册的 `/v1/suppliers/register` 接口
- [ ] **注册验证**：手机号验证码校验、邮箱验证、营业执照 OCR 识别
- [ ] **注册状态**：需要 `status` 增加"待审核/审核中/审核通过/审核驳回/已禁用"等细分状态

### 2.2 多级审核流程

- [ ] **分阶段审核**：当前 `SupplierServiceImpl.audit()` 一次性审核通过（status 0→1），需要拆分为：
  - 初审（采购方）：基本信息核验
  - 复审（质量/财务）：资质有效期、银行账户、税务信息
  - 终审（系统管理员）：账号创建和角色分配
- [ ] **审核记录表**：每次审核独立记录，含审核人、审核时间、审核意见、审核阶段、审核结果
- [ ] **审核驳回后可重新提交**：驳回后供应商可修改信息再次提交

### 2.3 资质有效期管理

- [ ] **资质到期自动校验**：[SupplierQualification](file:///d:\.我的项目\供应商协同\backend\src\main\java\com\supplier\sourcing\entity\SupplierQualification.java) 已有 `validStart`/`validEnd`/`remindDays` 字段，但缺少：
  - 定时任务扫描即将到期的资质
  - 到期自动标记资质失效
  - 通知供应商更新资质
- [ ] **准入审核时强制校验资质**：审核通过时必须确保至少有营业执照在有效期内

### 2.4 审核通过后自动建账号

- [ ] **自动创建系统用户**：审核通过后自动在 `sys_user` 表创建供应商管理员账号
- [ ] **自动分配默认角色**：为新账号分配供应商默认角色和菜单权限
- [ ] **发送账号激活通知**：通过邮件/短信发送初始密码和登录链接

### 2.5 黑名单管理

- [ ] **黑名单生效范围**：当前仅在审核时校验，缺少：
  - 已准入供应商加入黑名单后自动禁用账号
  - 黑名单到期自动解除
  - 黑名单操作审计日志

### 2.6 供应商分类

- [ ] **供应商品类/分类管理**：`supplier_category` 表缺少对应的 entity/controller/service
- [ ] **供应商评级**：`rating` 字段存在但缺少评级计算逻辑（基于绩效、质量、交付综合评分）

- [ ] **rfq_supplier 表**：询价单邀请供应商表，`rfqId, supplierId, supplierName, inviteStatus, quoteId`
  - entity: `com.supplier.sourcing.entity.RfqSupplier`

### 3.2 报价截止自动处理

- [ ] **定时任务**：扫描 `quoteDeadline` 已过期的询价单，自动将状态改为"已截止"

- [ ] **截止后禁止修改**：截止后禁止供应商新增/修改/删除报价

### 3.3 自动比价

- [ ] **横向比价服务**：`com.supplier.sourcing.service.QuoteCompareService`
  - 按物料分组汇总各供应商报价
  - 对比维度：价格（含税/未税）、交期、付款条件
- [ ] **比价结果展示**：`QuoteCompareVO` 视图对象
- [ ] **供应商绩效权重**：接入 `supplier_performance` 评分纳入比价推荐

### 3.4 议价流程

- [ ] **议价记录表**：`quote_negotiation` 表，记录每轮议价的时间、金额、双方备注

### 3.5 定价与转订单

- [ ] **自动生成订单**：定价后自动调用 `PurchaseOrderService.create()` 生成采购订单
- [ ] **定价结果追溯**：定价记录表 `quote_award`，记录定价时间、定价人、定价金额、关联订单号

### 3.6 币种汇率

- [ ] **汇率管理**：`exchange_rate` 表，支持多币种汇率维护
- [ ] **报价时锁定汇率**：创建报价时从汇率表获取当前汇率，锁定在报价单上

## 八、模块间联动 — 待开发项

以下联动在当前代码中全部缺失，需要单独设计和实现：

| 触发源 | 动作 | 目标模块 | 优先级 |
|---|---|---|---|
| RFQ 定价 | 自动生成采购订单 | sourcing → order | 高 |
| 收货确认 | 自动创建质检任务 | logistics → quality | 高 |
| IQC 不合格 | 自动创建 NCR | quality 内部 | 高 |
| NCR 严重异常 | 自动创建 8D 报告 | quality 内部 | 高 |
| NCR 扣款 | 自动生成扣款单 | quality → settlement | 中 |
| 对账周期 | 自动汇总收货/退货/扣款 | logistics + quality → settlement | 高 |
| 三单匹配 | 自动匹配订单/收货/发票 | order + logistics + settlement | 中 |
| 扣款确认 | 纳入对账汇总 | settlement 内部 | 中 |
| 质检申诉 | 申诉通过后关联扣款调整 | quality → settlement | 低 |
