
| 🟡 | **validUntil** (LocalDateTime) | valid_until (DATE) | **类型不匹配：Java 是日期时间，DB 只有日期** |

**修复方案：** Java 改为 `LocalDate` 或 DB 改为 `datetime`：
```java

```
