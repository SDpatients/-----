## 二、purchase_order_detail（采购订单明细表）🔴 列名不匹配！

| 状态 | Java 字段 | DB 列 | 说明 |
|------|-----------|-------|------|
| ✅ | orderId | order_id | 匹配 |
| ✅ | lineNo | line_no | 匹配 |
| ✅ | materialCode～materialModel | — | 匹配 |
| ✅ | unit～quantity | — | 匹配 |
| 🔴 | **unitPrice** | ~~price~~ | **Java 字段映射错误！MyBatis-Plus 会自动将 `unitPrice` 映射为 `unit_price`，但 DB 实际列名是 `price`（不是 `unit_price`）** |
| ✅ | taxRate | tax_rate | 匹配 |
| 🟡 | ~~taxPrice~~ | tax_price | DB 有此列（含税单价），Java 缺少。且 Java 的 `unitPrice` 对应的是 `price`（未税单价），需要另加 `taxPrice` |
| ✅ | amount | amount | 匹配 |
| ✅ | taxAmount | tax_amount | 匹配 |
| ✅ | deliveredQty | delivered_qty | 匹配 |
| ✅ | receivedQty | received_qty | 匹配 |
| ✅ | qualifiedQty | qualified_qty | 匹配 |
| ✅ | deliveryDate | delivery_date | 匹配 |
| ✅ | remark | remark | 匹配 |
| 🟡 | ~~orderNo~~ | order_no | DB 有，Java 缺少 |
| 🟡 | ~~promiseDate~~ | promise_date | DB 有（承诺交期），Java 缺少 |
| 🟡 | ~~lineStatus~~ | line_status | DB 有（行状态），Java 缺少 |

**这是严重问题！** `unitPrice` 会被 MyBatis-Plus 映射为 `unit_price`，但 DB 中列名是 `price`。需要二选一：

**方案A（改 Java — 推荐）：** 使用 `@TableField` 显式映射列名
```java
@TableField("price")
private BigDecimal unitPrice;  // 未税单价

@TableField("tax_price")
private BigDecimal taxPrice;   // 含税单价
```

**方案B（改 DB）：** 重命名 DB 列
```sql
ALTER TABLE purchase_order_detail 
    CHANGE COLUMN price unit_price DECIMAL(18,2) NOT NULL DEFAULT 0.00 COMMENT '未税单价';
```

同时建议添加缺失字段：
```java
private String orderNo;
private LocalDate promiseDate;
private Integer lineStatus;
```
